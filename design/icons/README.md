# אייקונים של עולמות מוזיקליים ב־MelodyMath

תיקייה זו מרכזת את אייקוני הווקטור (SVG) של העולמות המוזיקליים המוטמעים באפליקציה.
כל עולם מוזיקלי מייצג מבנה מתמטי אותנטי מתוך מחקרי האפליקציה (`docs/research/`), ואינו קישוט גרפי בלבד.

## מפרט טכני של האייקונים
- **פורמט:** SVG וקטורי נקי ועצמאי (ללא תלויות חיצוניות).
- **רשת מידות (Grid / ViewBox):** `0 0 64 64` עם פינות מעוגלות של סקוורקל (`rx="14"`).
- **פלטת צבעים:** מעוגנת בטוקנים של MelodyMath (סגול `#6946e8`, טרקוטה `#d97757`, זהב `#ffd85d`, כחול `#3b82f6`, ירוק `#10b981`).
- **נגישות (a11y):** כולל תגיות `role="img"`, `aria-label`, `<title>` ו־`<desc>` בעברית ובאנגלית.
