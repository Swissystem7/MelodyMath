# ב׳ · חוק החילוף ופעולות הפוכות — מחקר נושא (Perplexity, 6.11.2026, 40 מקורות)

## 1. המבנה המתמטי: מה נשמר ומה מתבטל
- חילוף: 2+1 = 1+2 כי אותם שני חלקים = אותו שלם (לא "כך החוק אומר").
- הפיכות: 2+1=3 ⇒ 3−1=2, 3−2=1; הסרת חלק מחזירה את האחר; 2+1−1=2 בלי חישוב מחדש.
- חיסור אינו חילופי: 3−1 אפשרי, 1−3 לא (בלא-שליליים; בלי שליליים).
- רצף: הוספה/הסרה מוחשיות → חלק–שלם → משפחת תרגילים → ניבוי והסבר במספרים חדשים. 281 ילדים גן–ג׳: חישוב נכון ≠ שימוש בהפיכות (springer). תפיסה שגויה: "5 ועוד 3" ו"3 ועוד 5" = תהליכים שונים → תוצאות שונות.

## 2. המבנה המוזיקלי
- **משך:** חצי+רבע או רבע+חצי = 3 פעמות – שימור סכום משכים אמיתי. תיבת 3/4: שני הסדרים ממלאים אותה; הסרת הרבע משאירה 2 פעמות. הפסקה ≠ חיסור (שקט תופס זמן).
- AB/BA: רק כשמשכי A ו-B ידועים; השוויון במשך הכולל, לא בזהות המוזיקה (שרשור לא חילופי).
- קאנון/רטרוגרד/קריאה-ותשובה: לא מודלים להפיכות (נגינה לאחור ≠ החסרת מה שנוסף).
- מרווחים: מודל נפרד – עלייה בשניים וירידה בשניים מחזירות (צעדים מכוונים).
- דינמיקה ("חזק = חיבור"): שרירותי.

## 3. אימון אוזן
- הבחנה בין צליל של פעמה לצליל של 2 פעמות וסדרם ביחס לפעמה יציבה.
- בדיקה: "ארוך–קצר" או "קצר–ארוך" – בחירה + הקשת פעמה; אותו גובה ועוצמה; כלי וטמפו משתנים. למדוד: זיהוי סדר; החזקה ל-2 פעמות; שוויון משך הרצפים. סף 8/10.

## 4. ראיות
- בני 5: ביטול פעולה בכמויות מקורבות, לא בחשבון מדויק (pmc). התערבות ישירה בהפיכות עבדה בבני 8, מוגבלת בבני 5. MusiMath (ד׳, שברים). אין ראיה ישירה; לבדוק מול המחשה חזותית זהה.

## 5. מפרט תרגיל: "החלפנו סדר – מה נשאר?"
- **הצגה:** פס 3 משבצות [A A][B]; מעליו חצי ורבע בתיבת 3/4. אותו גובה: צליל רציף 2 פעמות, ואז צליל של פעמה; פעמה שקטה ברקע.
- **ניבוי** (לפני [B][A A]): "נגיע לסוף התיבה באותו זמן? הסדר יישמע זהה?"
- **מתמטי:** "2+1=3. האם 1+2 נותן אותו שלם? אם מסירים את B, כמה נשאר?"
- **"מה שמעת?":** "באיזה רצף הארוך הגיע ראשון? שניהם נמשכו 3 פעמות?" ואז A לבדו, בלי השלמה בהפסקה.
- **נכון:** שניהם 3; סדר שונה; אחרי הסרת B נשארות 2: 3−1=2.
- **טעות צפויה:** "נשמעים אחרת, לכן הסכום שונה" → "המקצב השתנה; בדוק מתי כל רצף מסתיים." אי-חילופיות: "אפשר להסיר פעמה מ-3; אפשר להסיר 3 מ-1 בלי לרדת מתחת ל-0?"
- **מקרה חדש:** 5 אדומים + 2 כחולים: הסדר משנה כמות? אחרי הכנסת הכחולים והוצאתם? (7; 5).
- **קבלה:** 2+2 → שני חצאים ב-4/4; 4+1 → שלם ורבע ב-5 פעמות; שינוי חלוקה משנה נקודות התחלה.
