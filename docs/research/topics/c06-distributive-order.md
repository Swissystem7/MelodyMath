# ג׳ · חוק הפילוג וסדר פעולות עם סוגריים — מחקר נושא (Perplexity, 6.11.2026, 42 מקורות)

## 1. המבנה המתמטי: תחום החזרה, לא רק תוצאה
- ב-3×(4+2) חוזרת 3 פעמים יחידה עם 4 וגם 2; ב-3×4+2 רק ה-4 חוזר. פילוג: כל חלק מוכפל: 3×(4+2) = 3×4 + 3×2.
- רצף: קבוצות שוות → שני חלקים בכל קבוצה → סימון מה חוזר → סוגריים → פירוק למכפלות → השוואה לביטוי בלי סוגריים.
- תפיסה שגויה: "רק סוגריים קודמים; אחר כך משמאל לימין" (240 תלמידי ו–ח). 3×4+2 לבדו לא מאבחן (גם משמאל לימין = 14) → להוסיף 2+3×4.

## 2. המבנה המוזיקלי: חזרה על מוטיב מורכב
- A = 4 פעימות תוף, B = 2 פעימות פעמון, פעמה למכה. 3×(4+2) = AB|AB|AB; 3×4+2 = A|A|A|B. חיבור = שרשור; כפל = חזרה; סוגריים = מה נכנס ללולאה.
- הסתייגות: ABABAB ≠ AAABBB מוזיקלית אף שאותו משך – המיפוי משמר מבנה חזרה; הפילוג משמר משך וכמויות, לא זהות.
- אין לכפות תיבות/משקל קבוע כשאורך המוטיב משתנה. "כפל = חזק"/"סוגריים = גבוה" שרירותי.

## 3. אימון אוזן: גבולות המוטיב
- זיהוי מוטיב חוזר והבחנה בין חלק שחוזר בכל מופע לסיומת שמופיעה פעם אחת.
- בדיקה בלי ציור: "הפעמון חזר בכל סבב" או "רק בסוף"; שחזור בתיפוף; כלי וקצב משתנים; סף 5/6.

## 5. מפרט תרגיל: "מה בדיוק חוזר?"
- **הצגה:** א: [תוף×4 | פעמון×2] ×3; ב: [תוף×4] ×3 + [פעמון×2]. כל סמל = מכה של פעמה; אותם קצב ועוצמה.
- **ניבוי:** "באיזו גרסה תשמע פעמונים אחרי כל ארבע מכות? איזו תימשך יותר?"
- **מתמטי:** "התאם 3×(4+2) ו-3×4+2 לציורים. מה חוזר 3 פעמים? כתוב את הראשון בלי סוגריים."
- **"מה שמעת?"** (ציור מוסתר): "תוף-פעמון שחזר 3 פעמים, או 3 קטעי תוף וסיומת פעמון אחת?"
- **נכון:** א = 3×(4+2) = 3×4+3×2 = 18 פעימות; ב = 14. בא׳ גם הפעמונים בתוך החזרה.
- **טעות צפויה:** "בא׳ יש 14" → "השארת את הפעמונים מחוץ ללולאה."
- **מקרה חדש:** 2 שקיות × (5 אדומים + 3 כחולים) = 16 מול 2×5+3 = 13; ו-3+2×5 = 13 (לא 25).
- **קבלה:** 3→2 משנה חזרות; 4→5 אורך התוף; הסרת סוגריים מוציאה פעמון מהלולאה; (3×4)+2 – לא משנה צליל (כתיב בלבד).
