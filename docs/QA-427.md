# בדיקות שרת לעיצוב, למד הקצב ולמסך הראשון (#427)

משימת לווי ל-#423, #424, #425, #426. לכל PR שנפתח באחד מהם:

1. `npm test` (Node 22+, בלי התקנה). `test/designQa.test.js` בודק:
   - ניגודיות AA ‏(4.5:1) לכל טוקן טקסט מ-`src/sefirot.css` על כל משטח (`--bg`, `--card`, `--accent-soft` בסגול ובפטל, `--surface-2`), ותווית לבנה על כל מילוי פעולה וסטטוס.
   - טוקני מילוי (`--yellow`, `--joy`, `--sky`, `--mint`, `--line`, `--bg`) אף פעם לא צובעים טקסט. טוקן חדש בלי תפקיד בבדיקה נכשל.
   - רצפת 44px לכל פקד, ושאף כלל ב-`theme.css`/`sefirot.css` לא מקטין פקד מתחתיה.
   - מסך ראשון: `lang="he" dir="rtl"`, ולכל כיתה לכל היותר 3 בחירות חיזוק.
   - מד קצב: תלמיד חלש, בינוני וחזק מקבלים «צריך חיזוק», «בקצב» ו«מקדים» דרך אותו מסלול שהדוח למורה משתמש בו (תוכנית ← קצב ← HTML). מילת הסטטוס עוברת AA, ואף מילה לא מתייגת את הילד.
