# הערות תיוג תכנית — MelodyMath

## דחיות מפורשות (לא לעשות)

1. **אין שינוי שם `strand`→`domain` / `standard`→`clause` בכל הקוד.**
   החוזה הקיים הוא `{grade, strand, standard}` (`banks.js`, `isShippable`, בדיקות).
   במקום זאת: כינויים (`aliases`) על פריטים משוגרים — `domain = strand`, `clause = standard` —
   וייצוא קבוצות סגורות `CLOSED_DOMAINS` / `CLOSED_CLAUSES`.

2. **«אף סעיף לא מופיע פעמיים באותה שכבה» אינו אומר פריט בנק אחד לכל סעיף בכל כיתה.**
   50 סעיפים כוללים כמה פריטי תרגול בכוונה.
   המשמעות הנכונה:
   (א) מחרוזות הסעיפים הסגורות ב־`ST` ייחודיות;
   (ב) אותו זוג `(grade, clause)` לעולם לא ממפה לשני תחומים שונים (בדיקת התנגשות).
   בכשל — מדפיסים את העבריינים.
